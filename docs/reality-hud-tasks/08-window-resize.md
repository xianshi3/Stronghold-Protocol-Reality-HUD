# 任务 08：窗口整体缩放

## 任务目标
为三个伤害窗口提供独立的整体宽度/高度拖动、边界限制、位置边界和配置保存。

## 修改文件
- `hud.js`
- 本地游戏 `public/mods/reality-hud/hud.js`

## 数据流变化
- 玩家和敌人窗口使用各自 `width / height` 配置。
- 拖动右下角 grip 调整窗口整体尺寸。
- 尺寸受视口、最小宽高和最大宽高限制。
- 视口变化时三个窗口重新限制在屏幕内。
- 保存并恢复三个窗口的宽高。

## 已完成内容
- 玩家和敌人窗口增加 resize grip。
- 干员、玩家、敌人窗口均保存宽度和高度。
- 玩家/敌人窗口重新打开时恢复高度。
- 窗口尺寸受 `320–860px` 宽度和 `220–900px` 高度范围限制。
- 视口变化时重新限制窗口位置。
- 本地游戏 HUD 文件已同步。

## 修复内容
- 创建玩家/敌人窗口时恢复保存的 `cfg.height`。
