# 任务 11：增益/减益中文名称映射

## 任务目标
让增益、减益和技能效果显示实际中文技能名称或效果名称，不再只显示“技能”或变量名。

## 修改文件
- `hud.js`
- 本地游戏 `public/mods/reality-hud/hud.js`

## 数据流变化
- 普通效果优先查询 `effects.json`。
- 技能事件根据干员 `defId` 和 `skillIndex` 查询 `chess.skills[].name`。
- 技能数据尚未加载时先使用兜底文本，数据加载完成后刷新已存在效果。
- 常见状态变量继续使用中文兜底映射。

## 已完成内容
- 增加 `damageSkillName` 技能名称解析。
- 干员单位记录保存 `skillIndex`。
- `skill` 状态事件优先使用实际技能中文名。
- `refreshDamageNames` 在 `chess/effects` 数据加载后刷新技能名称。
- 已有 `effects.json` 名称映射和变量名中文兜底继续保留。
- 本地游戏 HUD 文件已同步。
