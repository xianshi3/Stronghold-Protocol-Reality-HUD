# 任务 05：敌人伤害聚合

## 任务目标
按敌人类型记录敌方对我方干员/召唤物造成的本回合和全局伤害、伤害类型以及受伤单位明细。

## 修改文件
- `hud.js`
- 本地游戏 `public/mods/reality-hud/hud.js`

## 数据流变化
- 增加 `state.damage.enemies`。
- 敌人以 `defId` 为主键合并为敌人类型记录。
- 每个敌人类型保存总伤害、伤害类型和目标干员明细。
- 敌人名称优先从 `enemies` 数据表解析中文名。
- 回合切换清空当前值，保留全局值；对局重置清空全部敌人记录。
