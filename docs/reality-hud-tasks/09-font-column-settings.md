# 任务 09：字体和列宽设置

## 任务目标
统一三个窗口的字体缩放，并支持玩家、干员、敌人窗口各自的列宽拖动和持久化。

## 修改文件
- `hud.js`
- `hud.css`
- 本地游戏 HUD 集成文件

## 数据流变化
- 三个窗口继续共享字体缩放设置，设置变更立即同步到所有窗口。
- 每个窗口拥有独立 `columnWidths`。
- 玩家列使用 `--rh-player-col-*` 变量。
- 干员和敌人列使用 `--rh-damage-col-*` 变量。
- 所有列都有最小宽度和最大宽度。

## 已完成内容

- 敌人窗口增加敌人、当前、全局、伤害类型、受伤干员列宽拖动。
- 干员窗口列宽配置迁移到 `windows.operators.columnWidths`。
- 保留旧版顶层列宽配置兼容。
