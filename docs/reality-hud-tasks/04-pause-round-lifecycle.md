# 任务 04：暂停和回合生命周期

## 任务目标
游戏暂停或回合结束时停止伤害和增益/减益计算；暂停时效果时间显示为 0 秒，回合结束时清空效果记录，下一场战斗重新开始。

## 修改文件
- `hud.js`
- 本地游戏 `public/mods/reality-hud/hud.js`

## 数据流变化
- 增加 `collecting / paused / finished / phase` 生命周期状态。
- 战斗阶段为 `COMBAT / UNITE / FINAL_ASSAULT / HIDDEN_CORE` 时才采集。
- `m.field`、`b.start` 和 runner state 可启动采集。
- 暂停时保留伤害数值，阻止快照、事件和效果更新，效果显示为 0 秒。
- 非战斗阶段结束采集并清空效果和攻击来源队列。
- 结算快照可在停止采集后补齐最终高水位一次，但暂停时仍拒绝处理。
