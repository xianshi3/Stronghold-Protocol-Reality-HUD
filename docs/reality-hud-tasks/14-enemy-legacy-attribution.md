# 任务 14：敌人旧事件来源归属

## 任务目标
兼容没有来源 ID 的旧版 `atk → dmg` 事件，使敌人对干员或召唤物的伤害也能按敌人类型分类。

## 修改文件
- `hud.js`
- 本地游戏 `public/mods/reality-hud/hud.js`

## 数据流变化
- 攻击来源 FIFO 同时保存“干员→敌人”和“敌人→我方单位”的攻击。
- 无来源伤害从目标对应队列取出来源后，统一进入干员或敌人聚合器。
- 队列仍按目标隔离、按时间过期，并在回合/对局结束时清空。
