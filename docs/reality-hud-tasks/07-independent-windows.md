# 任务 07：三个独立窗口

## 任务目标
将玩家、干员、敌人伤害拆分成三个独立的可移动窗口，分别挂载各自的数据选择器。

## 修改文件
- `hud.js`
- `hud.css`
- 本地游戏 HUD 集成文件

## 数据流变化
- 增加 `operators / players / enemies` 三个窗口配置。
- 干员窗口使用 `operatorDamageRows`。
- 玩家窗口使用 `playerDamageRows`。
- 敌人窗口使用 `enemyDamageRows`。
- 三个窗口分别挂载、显示和关闭，但仍共享总开关。

- 三个窗口分别保存位置和折叠状态。
